# Native V3.1 Research Baseline Reconstruction

This is a verified reconstruction of the native V3.1 baseline from preserved
artifacts because the original V3.1 source state was never committed. It is not
the original historical commit.

## Source recovery

The reconstruction starts from the V2 freeze (`e9943d2`) and restores the
pre-correction V3.1 source snapshots found in the local Git object database:

- Structural regime module: `40b239c0e147582f9ae46732fce83ad1151431c3`
- Native V3.1 replay module: `aef5b866c9a1608e8cae52df184f3719838402b8`
- Baseline structural tests: `f9d13d535d12ef2c910412aac1d3d4ece68a2683`
- Baseline replay tests: `42f9e0410c2416d165b21dfba3549fb4e5a0de9a`

The replay uses the original causal candidate classifier and two-session
hysteresis. It does not include the later active-regime invalidation,
corrected-RANGE persistence, or anti-churn state machine. Candidate confirmation
uses the existing two-session setting; no thresholds were changed for this
reconstruction.

Checkpoint/resume support, native PIT replay, the stricter H1 buyer-control
rule, and the portfolio ranking behavior are present and covered by the
relevant tests.

## Verification

A clean replay was run for 2023-01-01 through 2024-12-31 into
`data/processed/backtests/top_down_swing_v3_1_native_reconstructed/`. No
2025/2026 data or saved V2 signal artifacts were used.

The reconstructed outputs match the preserved old-native outputs:

- 24,762 regime rows: exact row-by-row match
- 77 emitted signals: exact row-by-row match
- 43 portfolio trades (42 closed, 1 open): exact row-by-row match
- 495 equity-curve rows: exact row-by-row match
- 43 same-execution zero-cost trade rows: exact row-by-row match
- Replay and portfolio summaries: exact match except for the output-directory
  path

Key portfolio metrics also match: win rate 57.14%, gross PF 3.047, net PF
2.636, gross P&L INR 30,423.32, net P&L INR 26,837.13, max drawdown -5.64%,
transaction costs INR 3,614.73, and average deployment 25.84%. The year-level
net P&L is INR 26,709.80 for 2023 and INR 127.33 for 2024.

The replay reports 24,762 regime rows, zero out-of-PIT regime/signal rows,
`native_replay=true`, `v2_signal_artifact_used=false`, and
`2025_2026_loaded=false`. EMA availability and regime distribution match the
preserved baseline summary.

Targeted verification passed: 50 tests covering causal structure/EMA, PIT
eligibility, H1 and setup behavior, portfolio ranking, and checkpoint/resume
determinism. `git diff --check` passed.

V2 strategy and backtest modules are unchanged. The only change to the existing
universe provider is an additive date-eligibility query used by the V3.1 PIT
audit. Later corrected-regime and anti-churn work is preserved separately on
branch `v3.1-regime-experiments-preserved` and is not part of this reconstruction.

The source and output artifacts are research-only and do not enable broker
orders or live trading.
